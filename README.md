# Oh, Paris ✦ | Luxury Café Experience
A luxury, Parisian-inspired café website built to showcase high-end visual storytelling, smooth scrolling interactions, and an elegant culinary menu.

🌐 **Live Website:** [View Live Deployment](https://paris-cafe-theta.vercel.app/)  
🔒 **Repository Status:** Private Portfolio Project

---

![Oh, Paris Hero Preview](PARIS-CAF.jpg)

> **Hero Experience:** *A TASTE OF PARIS* — **Oh, Paris ✦** (*"Where luxury meets the art of French café culture."*) featuring top navigation (**Home**, **About**, **Menu**, **Experience**, **Contact**), a **Discover Our Café** CTA button, and a smooth scroll prompt over a dark, gold-accented Parisian café backdrop.

### Key Project Features
* **Luxury Café Hero Section:** Full-screen atmospheric opening with gold accents, editorial serif typography, and clear navigation (`Home`, `About`, `Menu`, `Experience`, `Contact`).
* **Interactive Menu & Experience Sections:** Showcases signature French coffee and pastry items alongside storytelling pillars (*French Craftsmanship*, `01` | *Luxury Atmosphere*, `02` | *Signature Pastries*, `03`).
* **Media-Rich Presentation:** Combines custom video clips and café imagery (`PARIS-CAF.jpg`, `INDEX.HTML`, `style.css`, `script.js`) deployed live on [Vercel](https://paris-cafe-e5xy4d9ne-voidchatofficial-creator.vercel.app/).
* **Responsive Frontend Architecture:** Built with clean HTML5, custom CSS3, and vanilla JavaScript for fast performance across desktop and mobile devices.
